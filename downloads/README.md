# 矿物宝箱 · 每格最多 3 个版

适用 Minecraft Java 1.21.10 + Fabric。基于用户提供的 v1.2.2 textures JAR 修改。

- 每格最多 3 个物品；保留生成组数、物品种类、出现概率和贴图。
- 同一种物品仍可能出现在不同格。已生成的宝箱不受影响。
- 退出游戏，移除旧版模组 JAR，将此版本放入游戏实例的 mods 文件夹。
- 需要匹配版本的 Fabric Loader 和 Fabric API；ZIP 不包含这些依赖。

验证：840 个数量/堆叠上限测试通过，并检查生成组数、物品元数据保留、满箱行为和 JAR 完整性。未进行 Minecraft 游戏内实测。
