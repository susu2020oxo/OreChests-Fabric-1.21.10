# 压缩世界 · Minecraft Java 26.2 Fabric

版本：1.0.0-beta.3（可安装测试版）

## 安装

1. 在启动器中选择 **Minecraft Java 26.2**，安装 **Fabric Loader 0.20.1 或更高版本**。
2. 游戏 Java 运行环境选择 **Java 25**。
3. 将安装包 `mods` 文件夹中的两个 `.jar` 文件放进该实例的 `mods` 文件夹：
   - `compression-world-26.2-1.0.0-beta.3.jar`
   - `fabric-api-0.161.0+26.2.jar`
4. 已装同版本 Fabric API 时保留一份即可。联机时客户端和服务端都要装这两个模组。
5. 先在新建测试世界体验。本模组会保存自定义方块和物品组件；原世界应先备份，不能在移除模组后直接加载含巨型方块的存档。

这是 Java 版模组，不能装到手机基岩版。不要把 ZIP 本身放进 mods，也不必放入源码 ZIP。

## 如何压缩：直接使用原版工作台

**不需要压缩器。** 四个完全相同的物品，在原版3×3工作台中这样摆放（四角和中心留空）：

| 空 | 物品 | 空 |
|---|---|---|
| 物品 | 空 | 物品 |
| 空 | 物品 | 空 |

合成一个高一级压缩物品，最高五级。类型、等级、耐久、附魔和其他组件必须相同。四把武器和四件装备各占一格，也可以直接合成。

这个菱形配方适用于全部可压缩物品。四块木板摆2×2仍合成原版工作台；四块沙子摆2×2仍合成砂岩，不会抢占原版配方。压缩过的物品不参加普通原版材料配方，避免误用。

压缩器的合成配方和创造栏入口已经移除。仅保留旧版已有压缩器的物品ID及使用功能，避免旧存档物品丢失；新版流程不依赖它。

### 方块与作物

- 方块保持原版材质模型，放大成一个整体；有对应体积的实际碰撞。植物不具有实体阻挡。
- 放置需要完整空位，不覆盖已有建筑、方块实体或实体。挖掘任何一个部位都会移除整个巨型方块。
- 普通掉落按对应原材料总量 ×4、×16、×64、×256、×1024 计算，采用原方块战利品规则；工具是否合适和精准采集等仍影响结果。
- 巨型方块挖掘时间随等级提高。普通工具和压缩工具均可挖掘；精准采集取得对应原方块的多倍数量，不会直接返回同等级压缩块。
- 含容器组件或方块实体数据的物品，拆除时返回原压缩物品，避免复制或丢失内部内容，不额外倍增内容。
- 小麦、胡萝卜、马铃薯、甜菜、下界疣、可可、甜浆果具有巨型生长处理；自然成长周期为约5秒一级，需符合适用的光照条件。骨粉能加快成长。
- **beta3 新增下文列出的储物、附魔、酿造、锻造、红石送料等机器功能。未列出的特殊工作方块仍不保证拥有原版交互。**

### 新版：多格巨型熔炉

| 压缩等级 | 同时烧炼组数 | 总物品槽位 |
|---|---:|---:|
| 1 | 2 | 6 |
| 2 | 4 | 12 |
| 3 | 8 | 24 |
| 4 | 16 | 48 |
| 5 | 32 | 96 |

- 每组独立拥有一个原料槽、一个燃料槽、一个产物槽，可以同时烧不同物品。空手或非潜行状态右键巨型熔炉打开。
- 界面每页16组，使用原版大箱子界面呈现。第1、4行为原料，第2、5行为燃料，第3、6行为产物；最右一列是说明与翻页按钮。五级有两页，隐藏页也继续烧炼。
- 右上两支箭分别是上一页、下一页。产物不能塞入物品，按钮不能取走，支持Shift快速取出产物、放入可烧炼原料或燃料。
- 每组保留对应原版烧炼时长；高炉与烟熏炉使用各自配方和时长。此升级增加并行组数，不再额外叠加烧炼速度。
- 烧炼库存、各组燃料剩余时间和进度均保存；关闭界面不停止烧炼，区块卸载时暂停。
- 压缩原料在巨型炉中烧炼后保留压缩等级；压缩燃料在巨型炉中按材料总量延长燃烧时间。普通熔炉未扩展这两项，勿将压缩燃料当作普通燃料投入普通炉。
- 岩浆桶正常留下桶，压缩岩浆桶留下相同等级的桶。湿海绵烧炼遇到桶时会留下水桶。
- 取出产物结算已积累的烧炼经验。拆除或破坏巨型炉时，其内部物品只按实际数量掉落一次，不随方块倍率复制。
- 支持漏斗自动化：上方输入原料，侧面输入燃料，下方抽出产物或空桶。暂未提供每个炉槽的独立图形进度条。

#### 附魔台与书架

- 巨型附魔台外沿约8格内至少放置4个压缩书架。取附魔台等级与第4高书架等级的较小值；普通书架不提供压缩加成。
- 右键打开后，第1格放一件未附魔物品，第2格放青金石，第3格取产物。点击底行的附魔按钮。
- 生存需要达到30级，实际消耗3级经验和3颗青金石。按原版30级附魔随机生成，再将可升级附魔等级乘 2^有效等级，最高255；精准采集等只有一级的附魔保持一级。
- 例如有效压缩一级时，抽到锋利V会变成锋利X；没有合适书架时不能获得强化附魔。

#### 信标与压缩矿物底座

- 底座使用与信标同尺寸的压缩铁、金、钻石、绿宝石或下界合金块，按原版逻辑铺3×3第一层、5×5第二层，最多4层。这里每一格是一个完整压缩矿物块。
- 界面先放入一枚铁锭、金锭、钻石、绿宝石或下界合金锭，选择效果，再点击启用。上方须通向天空，可透光方块允许通过。
- 效果等级按 3^有效压缩等级设置；半径随等级和底座层数扩大，最高176格。可选速度、急迫、抗性、跳跃、力量、恢复。
- **等级倍率不等于所有属性最终数值的线性倍率。** 原版抗性、恢复频率等仍有机制上限；更高效果等级也不能绕开这些上限。

#### 可使用物品

- **经验瓶**：每级经验点数×10，保留原版随机基础经验；合并为最多8个高价值经验球，避免生成海量实体。倍率作用于经验点数，并非玩家等级直接×10。
- **水桶**：容量见表。右键水源收水，右键方块邻接空气放水；单次最多处理3×3、5×5、7×7、9×9、11×11平面内可操作格。Shift只处理一格。只收实际水源，记录余量，不覆盖建筑；水会蒸发的环境不放置水。
- **河豚**：每级毒性×2，食用产生强化中毒；手持攻击成功时让目标中毒5秒。强化毒仍不直接毒死目标。作为巨型酿造台材料时保留水肺配方，并延长药水时间。
- **骨粉**：同一平面3×3～11×11区域施肥，成功才消耗一个；Shift单格，可催熟巨型作物。
- **钓鱼竿**：每次成功收竿独立抽取2^L份原版战利品，实际概率仍由钓鱼条件和附魔决定。
- **剪刀**：剪羊产毛数量×2^L，剪叶等范围采集沿用压缩工具规则。
- **药水**：可升级效果提高等级；夜视、隐身、抗火、水肺、缓降等提高时长。喷溅药水与滞留药水扩大作用半径，依旧按实际命中和原版药水条件生效。
- **牛奶桶**：可清除效果2^L次，最后一次返回同等级空桶。手持压缩空桶可以给成年牛挤奶。
- **盾牌**：最大耐久×2^L，成功格挡提高击退。
- **不死图腾**：一枚具有2^L次保护次数，实际触发才扣一次；仍需持在手中，仍遵守原版图腾不保护的伤害类型。

### 新版：TNT每级威力×3

| 压缩等级 | 相对原版威力 | 爆炸强度参数（原版为4） |
|---|---:|---:|
| 1 | 3倍 | 12 |
| 2 | 9倍 | 36 |
| 3 | 27倍 | 108 |
| 4 | 81倍 | 324 |
| 5 | 243倍 | 972 |

- 支持打火石、火焰弹、红石信号、邻接明火、燃烧的箭点火，以及被爆炸引发连锁引爆。正常引线4秒，连锁引线更短；点火后巨型TNT轮流发光提示，不能再用普通挖掘拆除。
- **这是爆炸强度×3，不代表半径只增加3格。** 高等级仍具有很大的破坏力，实体伤害会考虑距离和遮挡。
- 使用与原版类似的射线能量和方块抗爆性计算，分批处理：每刻最多8192个射线步、最多512个目标方块。大型爆炸会在引爆之后继续计算、分批清除地形，不是一次性卡住服务器完成。
- 不强制加载或生成新区块；仅影响已加载且位于世界边界内的区域。保留基岩等不可破坏方块。实际范围受抗爆性、随机射线、世界高度和加载范围影响。
- 为避免海量掉落实体，大型爆炸不生成普通地形方块掉落；巨型熔炉库存仍只掉落实际内容。
- 未引爆的引线状态可保存；已经引爆后正在处理的破坏任务不会跨服务器重启继续。请等大爆炸结束再关服。
- 你这次修改只针对TNT；弓箭仍保留原来的每级×10数量。

### 战斗、装备与工具

- 武器基础攻击属性按2的等级次方强化，保留原物品类型和附魔。成功近战攻击会伤害目标周围等级对应半径（1～5格）内的其他可见目标；跳过本人、友方和不允许的玩家伤害。
- 防具护甲、韧性属性提高，并对穿戴压缩护甲的实体增加相应减伤。绕过护甲的伤害仍绕过护甲；不是所有伤害都能免疫。
- 工具按视线主方向挖掘一个平面，每刻最多额外处理24块，按实际工具消耗耐久。只扩展到工具擅长且可采集的方块，不连锁挖掉容器或其他巨型方块。
- **按住 Shift 单格挖掘**；切换工具或离开时会停止未完成的扩展挖掘。扩展挖掘继续使用原版破坏流程和 Fabric 破坏回调。

### 弓箭

- 弓箭每级箭数再乘10，额外箭的基础伤害随压缩等级提升。弩的普通箭也获得额外箭雨；烟花弹不复制。
- 一次正常射击只按原版规则消耗箭和耐久，额外箭不可捡回，保留对应箭类型。
- 高等级**持续分批发射**，不是同时创建10万个实体：每刻最多128支额外箭，最多2048支额外箭存活，额外箭6秒后清理。因此五级箭雨可能持续数分钟。
- 最多排队64轮；队列满时会提示，本次只射正常箭。退出或死亡会取消该玩家未完成的队列；队列不跨服务器重启保存。
- 使用 `/compressionworld stop` 停止自己的箭雨并清除自己的额外箭。

### 食物与生命

- 所有压缩物品持有、掉落和展示模型随等级放大：1.15、1.30、1.45、1.60、1.75 倍，最高 1.75 倍；第一人称略向外、向下偏移，界面物品格保持正常尺寸。
- 营养与饱和恢复属性提高，实际饱食度和饱和度仍受原版上限限制；本版不扩展饥饿条。
- 压缩食物可以在吃饱时食用，每次增加2×等级点生命上限。新增上限保留在存档中，死亡重生也保留。默认额外上限最多1004点，即普通玩家总上限1024点。

### 生物身体

- 玩家击败生物时额外掉落该种生物的身体；使用不死图腾模型，名称标明种类。
- 未压缩身体召唤1只；压缩后按8、16、32、64、128只召唤。
- 对方块右键使用，消耗一个身体。高等级在周围分散生成，需要足够开阔且已加载的空间，避免生成后互相挤压。
- 召唤的是该物种的新个体，不复制被击败个体的背包、装备、交易、主人或其他NBT。

## 源码

源码见包内 `CompressionWorld_26.2_beta3_source.zip`。使用 Java 25，执行 `gradlew.bat build`（Windows）或 `./gradlew build`（Linux/macOS）。首次构建需要联网下载 Gradle、Minecraft 与 Fabric 依赖。

交付 JAR 直接对官方26.2类和匹配Fabric依赖编译，并通过实际加载检查；附带的标准Loom工程供后续维护，未在此环境完成其Gradle构建验证。

Fabric 官方：https://fabricmc.net/use/installer/
Fabric API：https://modrinth.com/mod/fabric-api
本包不包含 Minecraft 本体或 Java 安装器。
